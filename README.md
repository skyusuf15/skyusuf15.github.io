# Yusuf Sanusi (Yusuf Korede) - Portfolio

[![Website](https://img.shields.io/badge/Website-Live-brightgreen.svg)](https://skyusuf15.github.io)
[![Developer](https://img.shields.io/badge/Developer-Senior_Backend_Engineer-blue.svg)](https://www.linkedin.com/in/skyusuf15/)

The personal portfolio, resume, and professional showcase for **Yusuf Sanusi**, a Senior Backend Engineer and Fintech Systems Specialist. This site highlights over 9+ years of experience building high-performance, scalable backend systems using technologies like **NestJS, PHP, and PostgreSQL**.

## Features

- **SEO Optimized:** Equal weighting for both name variations (Yusuf Sanusi & Yusuf Korede, Sanusi).
- **Modern Premium Design:** Custom dark mode aesthetic, utilizing a deep navy slate background `#0f172a` with glassmorphic elements and glowing cyan/blue accents.
- **Semantic Structure:** Fully restructured in HTML5 to ensure accessibility and quick rendering speeds. Clean architecture without heavy frameworks. 
- **Micro-Animations:** Smooth hover states and a floating orb background effect that emphasizes a premium feel.
- **Dynamic Elements:** Javascript auto-updates the footer copyright year to avoid maintenance overhead.

## Technologies Used

* **HTML5:** Semantic architecture with an accessible DOM.
* **Vanilla CSS (CSS3):** Flexbox, CSS Grid layouts, and custom design tokens (variables).
* **Vanilla JavaScript:** Zero unneccessary heavy libraries (e.g. jQuery has been removed for better performance).
* **Typography:** `Inter` and `Space Grotesk` from Google Fonts. 
* **Icons:** FontAwesome for social and structural iconography.

## Running Locally

To preview or modify the portfolio locally, simply clone the repository and open `index.html` in your browser. 
If you wish to serve it locally using a server:

```bash
# Using Python 3's built-in server
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080/` in your browser.
